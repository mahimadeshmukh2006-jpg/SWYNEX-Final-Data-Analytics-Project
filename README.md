## Titanic Passenger Data Analytics — Final Case Study

## 1. Project Overview

This project presents an end-to-end data analytics case study using the Titanic passenger dataset.

The objective is to clean raw passenger data, perform exploratory data analysis, identify meaningful patterns, and build an interactive dashboard to communicate the findings.

## 2. Problem Statement

Analyze Titanic passenger data to understand survival patterns based on gender, passenger class, age, fare, and family size.

The project aims to convert raw data into meaningful insights that can support better data-driven understanding and decision-making.

## 3. Dataset Information

- Dataset: Titanic Passenger Dataset
- Source: Seaborn public GitHub repository
- Original records: 891
- Original columns: 15
- Tools: Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly and Streamlit

## 4. Data Cleaning and Preparation

The raw dataset was inspected and cleaned by:

- Identifying and handling missing values.
- Detecting and removing duplicate records.
- Standardizing text values.
- Handling data types.
- Preparing a cleaned dataset for analysis.

**Cleaning Results:**
- Original records: 891
- Final cleaned records: 778
- Missing cells before cleaning: 869
- Missing cells after cleaning: 0
- Remaining duplicate rows: 0

## 5. Exploratory Data Analysis

The cleaned dataset was analyzed using statistical summaries and visualizations.

Analysis included:
- Passenger survival distribution.
- Gender-wise survival analysis.
- Passenger class-wise survival analysis.
- Age distribution and age-group survival.
- Fare distribution.
- Family size and survival patterns.
- Embarkation port analysis.
- Correlation analysis.

## 6. Key Findings and Business Insights

1. Overall survival rate was 41.52%.
2. Female passengers had a survival rate of 74.06%, compared with 21.86% for male passengers.
3. First-class passengers had a survival rate of 63.68%, while third-class passengers had 25.94%.
4. Children had a survival rate of 57.35%.
5. Senior passengers had a survival rate of 22.73%.
6. Passengers travelling in small family groups generally showed better survival rates than some larger family groups.

These findings describe associations in the dataset and do not establish causation.

## 7. Interactive Dashboard

An interactive dashboard was developed using Streamlit, Pandas and Plotly.

Dashboard features:
- Total passenger count.
- Total survivors.
- Survival rate.
- Average age and fare.
- Gender and passenger class filters.
- Age-group and survival-status filters.
- Interactive charts and passenger data table.
