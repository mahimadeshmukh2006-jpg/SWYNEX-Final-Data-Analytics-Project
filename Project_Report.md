# Final Data Analytics Project Report

## Project Title
Titanic Passenger Data Analytics

## 1. Introduction
This project analyzes Titanic passenger data to identify factors associated with passenger survival. It covers data cleaning, exploratory data analysis, visualization and interactive dashboard development.

## 2. Objective
- Clean and prepare passenger data.
- Analyze passenger demographics and survival patterns.
- Identify important trends through visualization.
- Present findings using an interactive dashboard.

## 3. Dataset
- Dataset: Titanic Passenger Dataset
- Original records: 891
- Cleaned records: 778
- Columns: 15

## 4. Data Cleaning
Missing values, duplicate records, inconsistent text values and data types were handled using Python and Pandas.

## 5. Exploratory Data Analysis
The analysis examined:
- Gender and survival
- Passenger class and survival
- Age groups and survival
- Fare distribution
- Family size and survival
- Embarkation port

## 6. Important Results

| Metric | Result |
|---|---:|
| Total cleaned passengers | 778 |
| Survivors | 323 |
| Overall survival rate | 41.52% |
| Female survival rate | 74.06% |
| Male survival rate | 21.86% |
| First-class survival rate | 63.68% |
| Third-class survival rate | 25.94% |

## 7. Dashboard
The Streamlit dashboard provides interactive filters, KPI cards, charts and passenger data.

The project demonstrates the complete data analytics workflow, from raw data preparation to interactive visualization. It helped develop practical skills in Python, data analysis, visualization and communicating insights.
